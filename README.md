소켓부터 HTTP까지 구현했다.
소켓은 기본부터 멀티스레드 서버와 마지막엔 실무에서 사용하는 멀티리액터 epoll구조 서버까지
실행 방법은 각 번호에 해당하는 폴더로 이동 후
./server로 서버 실행
./client로 클라이언트 실행
(폴더마다 실행파일 이름이 다르거나 방법이 다를 수 있음)
Latency 체크하는 클라이언트는 ./client 100 3과 같이 입력하면
100개의 클라이언트를 3초동안 연결해 PING 패킷을 마구 날린다.

정확히 이 문장과 반대되는 프로젝트를 했다.
바퀴 전문가가 되려면 바퀴를 직접 만들어 보는 것이 가장 빠른 길이라 생각한 것이 이유다.

하지만 나에겐 바퀴를 무에서 창조할 만큼의 시간 여유와 지능이 부족하다.

ai의 도움을 받아 개념을 채우고 코드를 채웠다.
하지만 어떤 부분이 어떤 동작을 하는지 정확히 이해했고,
문제가 생기면 무엇이 문제가 되는지 능동적으로 찾으려 했다.

실력 많고 똑똑한 개발자처럼 개발하진 않았으나 그들이 무슨 말을 하는지 알게 되었다. 

공부할 땐 ai를 쓰지 않고 공부해야 한다는 훌륭한 사람들의 의견도 많이 보았으나, 나의 경우 끈기가 부족하여 ai를 사용했다.
ai를 사용하지 말라는 사람들의 핵심적인 우려는 '너가 무엇을 하고있는지도 모르는 채로 개발하고, 개발한 것이 모두 너의 실력으로 개발했다고 착각하는 것이 문제다' 이다.

ai를 사용한 만큼 경각심을 가지고 더 깊게 파고 공부했다.
물론 ai없이 개발하는 힘은 안길러지겠지만
이미 ai는 나날이 발전하고 있고 앞으로도 ai없이 개발하진 않을 것이다.
그만큼 나는 ai를 쓰지 말라는 사람들의 핵심적인 우려를 해소하며 ai를'잘' 사용하기로 했다.
